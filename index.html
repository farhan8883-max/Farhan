About Me

PROFIL

Farhan Profile

UI/UX & Frontend Specialist
Online

Passionate Web Creator

Halo! Saya adalah seorang Frontend Developer & Creative UI Designer berpengalaman yang berdedikasi menciptakan antarmuka web modern, cepat, serta interaktif.

Spesialisasi saya berada pada pembuatan desain responsif, animasi halus, serta arsitektur kode clean berbasis HTML, CSS, JavaScript, dan React. Saya percaya bahwa setiap proyek web harus memiliki perpaduan nilai estetika tinggi dan fungsionalitas prima.

Selain melakukan perkodingan rutin, saya aktif mengeksplorasi tren UI/UX terkini, performa optimasi web, serta eksperimen efek visual unik seperti Glassmorphism dan animasi CSS 3D.

Pengalaman kerja meliputi pengembangan landing page interaktif, platform e-commerce responsif, hingga dasbor analitik berbasis komponen dinamis.

Siap membantu merealisasikan ide aplikasi web impian Anda dengan standar kualitas kode terbaik!
